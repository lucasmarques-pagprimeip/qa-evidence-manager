# 🧪 QA Evidence — Sistema de Coleta de Evidências

Sistema desenvolvido para **facilitar a coleta, organização e apresentação de evidências durante a execução de testes de software**.

A ferramenta foi criada com foco em **Quality Assurance (QA)**, permitindo centralizar informações importantes da execução dos testes e gerar uma documentação visual mais organizada para apoiar processos de validação, homologação e acompanhamento de qualidade.

---

## 🚀 Sobre o projeto

Durante o processo de testes, é comum que o profissional de QA precise coletar diversas evidências, como:

* 📸 Capturas de tela;
* ✅ Resultados de cenários de teste;
* 📝 Informações sobre a execução;
* 🔎 Evidências de comportamento esperado e obtido;
* 📋 Dados necessários para documentação de bugs;
* 📊 Informações para acompanhamento da qualidade.

O **QA Evidence** busca simplificar esse processo, proporcionando uma interface centralizada para organizar essas informações.

---

## 🎯 Objetivos

O projeto tem como principais objetivos:

* Reduzir o tempo gasto na criação de evidências;
* Padronizar a documentação dos testes;
* Facilitar a apresentação dos resultados;
* Melhorar a organização das evidências;
* Auxiliar na abertura e documentação de bugs;
* Tornar o processo de QA mais eficiente e rastreável.

## 🧪 Aplicação em Quality Assurance

A ferramenta pode ser utilizada durante diferentes etapas do processo de QA, principalmente em:

* Testes funcionais;
* Testes de regressão;
* Testes exploratórios;
* Homologação;
* Validação de correções;
* Testes de novas funcionalidades;
* Documentação de defeitos;
* Evidências para homologação.

### Fluxo sugerido

```text
Execução do teste
       ↓
Identificação do resultado
       ↓
Coleta da evidência
       ↓
Organização das informações
       ↓
Documentação
       ↓
Homologação / Registro do resultado
```
